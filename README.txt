YES BOSS WEBSITE - MUSIC
========================

Put your title theme here as:   theme.mp3

The Yes Boss page (yesboss.html) checks for this file. When it's there, a round
"Play the theme" button appears next to the Play Store button. When it isn't, the
button stays hidden, so the page works either way.

Use mp3 for the website (every browser plays it). Keep it under ~5 MB so the page
loads quickly; 128-192 kbps is plenty. It plays only when someone taps the button
(browsers block autoplaying music anyway) and it loops.
